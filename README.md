## Project 1 — Smart Sales and Inventory Tracker

**Live Website:** [https://sites.google.com/view/ssitab/home](https://sites.google.com/view/ssitab/home)

### Overview

The Smart Sales and Inventory Tracker (SSIT) is a web-based system prototype designed for businesses that manage consumer goods. It was built to replace error-prone manual tracking with a structured, automated solution. The prototype is modeled around a real-world distribution scenario involving PRAN products across warehouses and retail shops in Savar, Dhaka.

### Key Features

- Inventory tracking with real-time stock monitoring
- Order and delivery management for shop-level transactions
- Daily reports and revenue calculation
- Sales performance charts and visual analytics
- Search and analysis tools for business insights
- Multi-business support for managing more than one branch
- Integrated Google Calendar for scheduling
- Embedded Google Maps for location tracking
- Notification system for alerts and updates

### Website Pages

| Page | Description |
|---|---|
| Home | Introduction and system overview |
| Dashboard | Central control panel for data and stats |
| Add New Products | Form interface to add inventory items |
| Sales and Orders Report | View and filter order data |
| Search and Analysis | Query-based data exploration |
| Notifications | System alerts and updates |

## Project 2 — ITM Rescue Force

**Live Website:** [https://sites.google.com/view/itm-rescue-force/home](https://sites.google.com/view/itm-rescue-force/home)

### Overview

ITM Rescue Force is an emergency response system prototype powered by Information Technology, Management, and Artificial Intelligence. It is designed to coordinate fast and effective responses to disasters, accidents, health emergencies, animal rescues, and environmental threats. The system combines human teamwork with AI assistance to protect lives and restore safety.

### Key Features

- Emergency reporting interface for the public
- Live map and dashboard for tracking active incidents
- RescueGPT — an AI-powered assistant for guidance and response
- Admin control panel for managing rescue teams
- Volunteer and community engagement portal
- Covers multiple emergency types: disaster, accident, health, animal, and nature
- Integrated Google Calendar for response scheduling
- Gallery and team showcase pages

### Website Pages

| Page | Description |
|---|---|
| Home | Mission statement and system introduction |
| Live Map and Dashboard | Real-time incident tracking |
| Report an Emergency | Public-facing emergency submission form |
| RescueGPT (AI Assistant) | AI-powered guidance chatbot |

| Admin Control Panel | Back-end team management |
| How It Works | Step-by-step process explanation |
| About Us | Organization background and values |
| Our Team | Team member profiles |
| Gallery | Photos and media |
| Contact Us | Reach out for support or collaboration |

## Project 3 — Elemental Fusion Event Management

**Live Website:** [https://sites.google.com/view/elementalfusion/home](https://sites.google.com/view/elementalfusion/home?authuser=0)

### Overview

Elemental Fusion is a creative event management business based in Dhaka that provides full event planning and coordination for weddings, birthdays, corporate events, and social programs. The website prototype showcases how a modern, tech-enabled event company presents its services, tools, and portfolio to clients. The goal is to make every occasion stress-free and memorable by managing everything from planning to decoration.

### Vision

To become one of Bangladesh's most trusted and creative brands for event management through innovation and excellence.

### Mission

To deliver beautiful, well-planned, and affordable events that reflect creativity, professionalism, and Islamic values.

### Key Features

- Full event planning and coordination for weddings, birthdays, corporate events, and social programs
- Traditional wedding features including Palki and Ghorar Gari
- AI-powered planning and support tools
- Digital photo albums and custom print ordering
- Mobile app integration for client convenience
- AI-powered drone services for events
- Smart tools section for technology-enabled event management
- Events gallery showcasing past work
- Online consultation and booking contact page

### Website Pages

| Page | Description |
|---|---|
| Home | Welcome message and business introduction |
| Services | Full list of event planning and management services |
| Events | Portfolio of past events and work |
| AI and App | Smart tools and technology features for events |
| Photo Albums | Order custom photo albums and prints |
| About | Vision, mission, and company background |
| Contact | Consultation booking and inquiry form |

### New Innovations

Elemental Fusion is introducing AI-powered support, a dedicated website, a mobile app, AI-powered drone coverage, special traditional wedding features such as Palki and Ghorar Gari, and a custom photo album ordering platform for clients.
